# Security policy

## Supported versions

Only the latest release of AdbAux receives fixes.

## Reporting a security problem

Do not open a public issue for a security problem. Report it privately through GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**. Only you and the maintainer can see the report.

Include the AdbAux version (About tab), the Windows version, and the steps that show the problem. Remove your
phone's serial number from any log you attach.

AdbAux is maintained by one person in their free time. Reports are read and answered as soon as possible, but
there is no guaranteed response time. A confirmed problem is fixed in a new release, and its release notes say
what was fixed.

## Scope

This policy covers AdbAux itself (this repository). scrcpy and adb are separate projects: report problems in
scrcpy to its developers at https://github.com/Genymobile/scrcpy, and problems in adb to Google, which publishes
it as part of the Android SDK Platform-Tools.
