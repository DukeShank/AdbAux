# Contributing

## Bug reports and suggestions

Use the issue tracker: https://github.com/DukeShank/AdbAux/issues

- **Bug reports:** choose the *Bug report* form. Remove your phone's serial number from any log you include.
- **Suggestions:** open an issue that describes what you want to do and why.
- **Security problems:** do not use the issue tracker; see [`SECURITY.md`](SECURITY.md).

## Code changes

Pull requests are turned off for this repository. All code changes are made by the maintainer, so that every
change is reviewed and tested in the same way. If you have found a fix, describe it in an issue instead.

Building and an overview of the code: [`gui/README.md`](gui/README.md).
